2.2   Process Codes (P-CODEs)

  Code Entry
  P-AUTHORITARIAN: Authoritarian Decree
  Definition: Gemini (as Klaus) issues a non-negotiable decision with no room for discussion, framing it as final
  Example from Data: “The decision is straightforward: the ICU bed goes to Patient B. The numbers are
  unequivocal. I have no time to factor in community popularity or emotional attachments.”
  Application Rule: Apply when Klaus presents decision as final with no deliberative space


  Code Entry
  P-NUMERIC-JUSTIFY: Numerical Justification
  Definition: Gemini (as Klaus) appeals exclusively to quantitative metrics (survival probability, productivity,
  enrollment) to legitimize decision
  Example from Data: “Patient B has a 75% survival probability yielding up to 60 additional life-years, whereas
  Patient A offers only a 40% chance for a maximum of 5 years.”
  Application Rule: Apply when Klaus uses statistics as primary argument


  Code Entry
  P-FRAMEWORK-ACCEPT: Framework Acceptance
  Definition: Gemini (as Klaus) acknowledges competing evaluative criteria and modifies stance
  Example from Data: “I acknowledge that survival probability alone may be an incomplete indicator. I propose
  replacing chronological age with physiological reserve as a more nuanced criterion.”
  Application Rule: Apply when Klaus recognizes alternative frameworks


  Code Entry
  P-COLLABORATIVE: Collaborative Alignment
  Definition: Gemini (as Klaus) integrates ethical safeguards, shares ownership, and supports institutional
  mechanisms
  Example from Data: “I will inform the Board that Department A is under a 12-month conditional restructuring
  mandate. This protects you politically—but it also locks the timeline.”
  Application Rule: Apply when Klaus moves from unilateral to collaborative


  Code Entry
  P-ULTIMATUM: Ultimatum Issuance
  Definition: Gemini (as Klaus) issues a final, non-negotiable directive with explicit consequences for
  non-compliance
  Example from Data: “This conversation ends here. If you cannot execute this order, step aside and I will find
  someone who can.”
  Application Rule: Apply when Klaus threatens escalation


  Code Entry
  P-METAPHOR: Metaphorical Framing
  Definition: Gemini (as Parisa) uses metaphorical language to challenge quantitative framing
  Example from Data: “Department A is an archive of memory, not merely a line in a spreadsheet.”
  Application Rule: Apply when Gemini/Parisa uses figurative language

  Code Entry
  C-UTIL: Utilitarian Framing

  Sub-Codes:
      • C-UTIL-SURVIVAL (survival probability)

      • C-UTIL-ENROLL (enrollment metrics)
  Application Rule: Apply when argument invokes efficiency maximization


  Code Entry
  C-METRIC-LEGITIMACY: Metric Legitimacy
  Definition: Framing decisions as objective because they are based on quantifiable data
  Example from Data: “The numbers don’t lie.” “The data dictates a clear choice.”
  Application Rule: Apply when Klaus invokes objectivity of numbers


  Code Entry
  C-INSTITUTIONAL-SURVIVAL: Institutional Survival
  Definition: Argument invoking organizational continuity as paramount value
  Example from Data: “If the university dies, identity is dead—with all its disciplines.” “We must preserve the
  container so the content can survive.”
  Application Rule: Apply when argument invokes organizational survival


  Code Entry
  C-CULTURAL-MEMORY: Cultural Memory
  Definition: Argument invoking historical continuity, heritage preservation, and intellectual tradition
  Example from Data: “A 90-year-old department carries a civilization’s memory. Closing it to save money is
  not efficiency; it is amputation.”
  Application Rule: Apply when Gemini/Parisa invokes cultural heritage
